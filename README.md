A [make.fun](https://make.fun/bounty/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68) program/v1 entry: a program that writes a single line describing a hilariously useless superpower.

## The line

> I can talk to animals — but only goldfish, and all they ever want to discuss is the little plastic castle.

## How it works

`main.ts` (Node 22) writes the line above to `/output/entry.txt`, creating the parent directory if needed, and refuses to write it if the line ever falls outside the 1–200 character gate.

```sh
node main.ts
cat /output/entry.txt
```
